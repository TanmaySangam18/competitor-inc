# The Living Company — master build map (2026-07-12)

The vision, plainly: turn competitor.inc from a **skeleton** into a **fully-living AI company** with a
**compounding brain** — one that remembers everything, runs many specialized minds as one, uses every tool
it's connected to, checks its own work, and gets measurably smarter with every job. Competitor runs itself
on this brain and sells the same brain to customers.

**Honesty cap (never crossed):** "Lucy-level" = *continuously compounding capability*, NOT literal movie
super-intelligence or AGI. We aim as high as real engineering allows and never stop unlocking more — but we
never claim omniscience, never fake capability, and the safety floor (kill switch, spend caps, human-for-
high-risk, honesty, verify-before-done) is permanent and grows *with* the intelligence, not against it.

## The build phases — from ~40% alive → living body + compounding brain
Each phase ships in tested slices (branch → PR → qa + review → merge). Nothing claimed before its receipt.

**Phase 1 — Set the bones straight (Skeleton).** [UNDERWAY] The reset: one clean structure, delete dead code
for good, unify the ≥5 rosters into one, collapse governance to a single spine, make the backend headless
(core + CLI, already seeded). *Done-when:* one clean core, `npm run qa` green, the CLI operates it.

**Phase 2 — The nervous system (the Lucy core).** The leap from "parts" to "alive": agents that actually
**reason and coordinate together** — real deliberation (they debate, not read scripts), true delegate-down/
verify-up hierarchy, shared working memory feeding every decision, and one central planner that turns a goal
into coordinated work across the org. Plus the unified control panel (API + full CLI) to operate all of it.
*Done-when:* give the org a goal → agents plan, argue, split the work, verify each other, produce a real
result with a decision record — end to end, headless.

**Phase 3 — Wake the organs + connect the hands.** Every department goes live behind "connect once → runs
itself": email, Slack, calendar, GitHub, payments, leads, research, social, support. Sockets built by me;
each lights up when the founder connects it. *Done-when:* a connected department does real outside work
autonomously (within the rails: no spam, named-AI, caps).

**Phase 4 — Metabolism (money flows).** Payments in (Stripe Connect → the customer's account; Polar for our
subs), spend governed by caps, every real dollar → the honest ledger. *Done-when:* a real stranger pays; it
lands; it's on the books. → drives toward **$10k collected**.

**Phase 5 — The compounding brain (the Lucy ladder — never "done").** What makes it keep getting smarter:
- **Compounding memory** — every product/company the org touches makes the next one faster (shared graph).
- **Verification empire** — it tests its own work and *learns from every failure* (regressions can't return).
- **Self-improvement loop** — it reviews its own performance, proposes better playbooks, and (big changes
  gated to the founder) upgrades how it works.
- **Whole-brain coordination** — all agents + all memory + all tools aimed at one goal together.
*Measured-by:* capability goes up over time (a 5th product ships far faster than the 1st); failure rate drops.

**Phase 6 — Senses + reproduction (the product itself).** Perceive the market (competitor-watch, analytics,
customer signals) and — the whole point — **spawn and run NEW companies for customers**: Competitor builds
and operates a customer's AI company end-to-end. The body creating new bodies. *Done-when:* a customer's
company runs on the platform with the founder only touching high-risk approvals.

**Phase 7 — Skin/face (last).** Rebuild the beautiful frontend as a thin client over the live backend. It
comes last on purpose: a weak backend is expensive debt; a face is cheap to add once the body works.

## Invariants (grow with the intelligence, never weaken)
Honesty floor (no fabricated data/proof/capability) · verify-before-done · money & irreversible acts human-
approved · spend caps at the infra floor · kill switch · tenant isolation · named-AI disclosure, no spam ·
`npm run qa` green per slice · nothing claimed before its receipt.

## The Lucy thread (what "unlocking more of the brain" really means here)
Memory that never forgets · many minds coordinated as one · uses every tool it's connected to · checks and
corrects itself · improves its own playbooks · compounds with every job. Not a movie — an engineering
direction we never stop climbing.
