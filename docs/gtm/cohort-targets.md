# Cohort Lab — Outbound Target List (Cohort Owners)

**Product:** competitor.inc Cohort Lab license ($1.5–2.5k/mo) — 25–100 founder seats + a program-director evidence dashboard showing validation outcomes across the cohort (for funder reports, deans/donors, sponsors, grant compliance).

**Playbook:** Crossing the Chasm beachhead (NU → Boston/NE → national) + Blond concentric circles (warm first).

**Warmth key:** `WARM-NU` = Northeastern affiliation (founder's campus) · `WARM` = Boston/New England · `COLD` = national.

**Sourcing rules:** public info only; director names only where publicly listed on official pages; generic program emails only (no personal-contact harvesting); "—" = not publicly found (never guessed).
